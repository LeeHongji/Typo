## 1. 目标

用户说话时可以离开正在输入的窗口，去别处选一段文字或截一张图，把它们连同说的话一起送回原来的输入框。为此需要两件事：

1. 录音开始时记住文字要去的地方，之后不管用户切到哪里都送回那里。
2. 录音期间收集引用和截图，并在送达时放到合适的位置。

## 2. 锁定输入目标

### 2.1 记录

`Injection/DictationDestination.swift`。录音开始时在后台线程读取：前台应用、它的焦点窗口（及窗口服务器编号）、焦点元素（输入框）。辅助功能调用的超时为 0.15 秒，应用繁忙时很快放弃。

### 2.2 送达时的判定

`DictationDestination.plan` 是纯函数：

| 情况 | 计划 | 动作 |
|---|---|---|
| 用户没离开 | `pasteHere` | 与锁定之前完全一样地粘贴 |
| 前台是别的应用，或同一应用的别的窗口 | `bringBack` | 把应用、窗口、输入框带回并逐项确认后再粘贴 |
| 同一窗口，但输入框失去焦点（在窗口内选了文字来引用） | `refocus` | 重新聚焦输入框；无法确认时仍照旧粘贴 |
| 应用已退出 | `gone` | 不粘贴 |

只有「别的应用在前台」或「同一应用的别的窗口」才算离开。焦点元素读起来不一样不算，因为 Electron 会重建节点；已被应用重建、无法询问的输入框也不算。这样最常见的「没离开」路径行为不变。

带不回来或应用已退出时不盲贴：文字进剪贴板，录音条提示「已复制，原输入框不在了 / Copied — the original box is gone」，结果为 `copiedTargetGone`，Typo 露出受惊表情。

这一层接在原有的 `InjectionTargetPlan` 之后，只在 `.injectIntoCurrentFrontmost` 分支生效。自动化入口仍走 `.activateAndConfirm`。

## 3. 收集引用和截图

`Services/DictationAttachments.swift`。只在录音期间收集。

### 3.1 引用

在别处拖选、双击或三击选中文字即成为一条引用。读取顺序：辅助功能的选中文本，网页用文本标记，都不行时模拟一次复制并把剪贴板放回原样。在正在听写的输入框内选文字属于编辑，不算引用。单条上限 4000 字符。

### 3.2 截图

只由快捷键触发，不拦截鼠标点击。按键由 `Services/DictationShortcutTap.swift` 的事件监听在独立线程处理，可以与任何按住的听写键同时按：

| 按键 | 动作 |
|---|---|
| ⌥S | 截前台窗口 |
| ⌥⇧S | 屏幕变暗，拖出一个框截取（`UI/Attachments/RegionCaptureOverlay.swift`） |
| Esc（框选中） | 取消框选，不取消录音 |

在正在听写的窗口上按 ⌥S 会提示先切换窗口。截图用 ScreenCaptureKit，最长边 1600 px。Type4Me 自己的窗口不算。第一次需要截图时才申请「屏幕录制」权限；没有权限时托盘说明原因并提供前往设置的入口。

早期版本用「单击其他窗口即截图」，因为会把激活窗口的那一下点击也截进去，已在 `ff15b69` 移除。

### 3.3 反馈

`UI/Attachments/AttachmentEffects.swift`：捕获时在选区或窗口上闪一圈轮廓，一张卡片沿弧线飞向 Typo（Typo 在录音条上时飞向托盘）。录音条上方的托盘列出截图，每项可单独移除。录音条显示实时文字时，引用直接出现在文字中它被选取的位置；否则作为托盘里的条目。

## 4. 引用的位置

引用放在「开始选取之前说的那些话」之后：

1. 识别服务给出逐词时间（火山）时按时间定位。
2. 没有时，取开始选取 0.7 秒后屏幕上显示的文字作为锚点（识别滞后于语音）。
3. 最终结果到达后按最终的逐词时间重新定位。

经过会改写文字的模式（大模型后处理）时，引用以 `⟦Qn⟧` 标记随文字送入模型，返回时每个标记必须恰好出现一次，否则回退到不依赖标记的定位。

## 5. 送达格式

`DictationDelivery`：

| 内容 | 格式 |
|---|---|
| 短引用（单行且不超过 80 字符） | 放在句中，含中日韩文字用「」，否则用 “”；与相邻文字之间按需补空格 |
| 长引用或多行引用 | 独立成段，每行以 `> ` 开头，前后空行 |
| 截图 | 文字粘贴成功后逐张粘贴 |
| 截图（目标是终端） | 粘贴文件路径，路径按 shell 规则加引号；终端名单见 `DictationDelivery.terminalBundles` |

带引用的送达不走「可追踪注入」，因为粘贴的内容已不等于识别文字，无法用于后续的改口和纠正学习。

## 6. 存储

- 录音期间的截图文件在 `Caches/Type4Me/attachments`，保留一天。
- 历史记录保存引用（及其位置）、压缩后的截图、未完成的录音，随条目删除。实现在 `Database/HistoryMedia.swift`，目录 `Application Support/Type4Me/history-media`。
  - 截图：HEIC（不可用时 JPEG），最长边 1280 px，总量上限 300 MB。
  - 未完成的录音：AAC，保留 7 天。
- 数据库新增 `attachment_count` 列，追加在最后；保存的文字不含引用本身。
- 历史界面：`UI/Settings/HistoryAttachmentsView.swift`。
